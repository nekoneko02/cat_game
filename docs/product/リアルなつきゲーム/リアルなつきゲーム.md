# ねこ育成ゲーム
本プロダクトは、「できるだけリアルなねこ飼育体験を提供する」をコンセプトとして、ねこ育成ゲームです。

## core
### ミッション・ビジョン（プロダクトレベル）
- ミッション：ペットと人が理解し合い、適切な距離感を持てる世界をつくる
- ビジョン：ペットと人の関係を、IT技術がサポートする

### タグline
デジタルアニマルウェルフェア

- ねこ（ペット）を理解する
  - ねこは適切なふれあい方をされて幸せ（ペット目線）
  - ねこをより理解できて、ねことの関係が深まって幸せ（人目線）
- 適切な飼育できない状況で、ペットを飼わない選択肢を与える
  - 無理な飼育をされない（ペット目線）
  - ペットを飼わなくても幸せ（人目線）

### 事業戦略
- まずはプロダクト第1弾をリリースする
- →ユーザーの反応を見る（外的）
- →プロダクト開発の経験を得る（内的）
