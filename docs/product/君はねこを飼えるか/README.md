# 君はねこを飼えるか？

## プロダクト概要
- プロダクト名：君はねこを飼えるか？
- コンセプト：「ねこを飼うか迷っている人に、判断材料を与え、ゲームで疑似体験させ、より適切な判断を促す」
- アプローチ：責任感を押し付けるのではなく、**「気づき」を与える**ことを重視
  - 文字や写真だけでは理解しにくい日常の具体的な場面を疑似体験させる
  - 「○○という場面で、ねこがxxxという状況になる」という気づきを提供
  - 最終的な飼育判断はプレイヤー自身に委ねる

## ミッション・ビジョン・タグライン
- **ミッション（会社レベル）**：すべての動物が幸せな世界をつくる
- **ミッション（プロダクトレベル）**：猫を飼う前に適切な知識を学び、責任ある飼育を促進する
- **ビジョン**：飼育シミュレーションを通じて、猫と人の適切な関係性を構築できる社会を実現する
- **タグライン**：「飼う前に、猫を知ろう」

## ターゲット
- ねこを飼うか迷っている人
  - → [[ペルソナ定義]]: 主要ターゲットはBタイプ（調べても気づけない日常のリアルを体験させる）

## 課題
- → [[課題]]: 飼育放棄・殺処分を減らす、後悔する飼い主とストレスを抱える猫を減らす、ねこをより幸せにする飼い主を増やす　の3つの課題に取り組む

## 市場分析・競合優位性
- → [[市場分析]]: TAM 110～165万人/年、初年度目標1,000DL、売上22,500円
- → [[競合優位性]]: 双方向性×実践体験、いつでもどこでも、リアル性×楽しさ、専門家監修

## 判断材料
- → [[判断材料の整理]]: 22のカテゴリを「事前学習で防げるか」「基準が明確か曖昧か」で分類
  - 最優先は「捨てられてしまう原因」（問題行動、計画外の繁殖、想定外の事態、老齢期）
  - 次点は「後悔する原因」（日常のお世話、睡眠、衛生面など）と「猫を幸せにできるか」

## 成果目標（初年度）

### 定量目標

- **ダウンロード数**：10～50人
  - 想定流入：身内・技術ブログ読者など限定的なリーチ
  - 収益化は優先せず、フィードバック収集とプロダクト改善を重視
- **シナリオ完了率**：60%
  - 実際にゲームを最後までプレイしたユーザーの割合
- **行動変容率**：50%
  - プレイ前後のアンケートで「飼育に対する意識が変化した」と回答した割合
- **ユーザー満足度**：80%
  - 「気づきを得られた」「判断材料として役立った」という評価の割合

### 定性目標

- **深い気づきを得られたか**: ユーザーからの具体的なフィードバックで検証
- **ゲームの完成度**: バグが少なく、体験の質が高いこと
- **シナリオの網羅性**: 判断材料の整理で定義した優先度の高い体験をカバーできているか

## 成果測定方法

### アプリ内アンケート設計

実際の飼育行動や放棄率は追跡不可能なため、アプリ内での行動変容を測定します。

#### 1. 開始時アンケート（ゲーム起動時）

- **質問1**: 猫を飼いたいと思っていますか？
  - [ ] とても飼いたい
  - [ ] 少し飼いたい
  - [ ] 迷っている
  - [ ] あまり飼いたくない
  - [ ] 飼いたくない

- **質問2**: 猫を飼うことについて、どの程度調べましたか？
  - [ ] かなり調べた
  - [ ] 少し調べた
  - [ ] ほとんど調べていない

- **質問3**: 猫を飼う上で不安なこと・わからないことは何ですか？（自由記述）

#### 2. 終了時アンケート（シナリオクリア時）

- **質問1**: プレイ後、猫を飼いたいと思いますか？
  - [ ] とても飼いたい
  - [ ] 少し飼いたい
  - [ ] 迷っている
  - [ ] あまり飼いたくない
  - [ ] 飼いたくない

- **質問2**: このゲームで新しい気づきを得られましたか？
  - [ ] 多くの気づきがあった
  - [ ] いくつか気づきがあった
  - [ ] 少し気づきがあった
  - [ ] ほとんど気づきがなかった

- **質問3**: 具体的にどのような気づきがありましたか？（自由記述）

- **質問4**: このゲームは判断材料として役立ちましたか？
  - [ ] とても役立った
  - [ ] 役立った
  - [ ] 少し役立った
  - [ ] あまり役立たなかった

#### 3. 測定指標

- **行動変容率**: 開始時と終了時のアンケートで「飼いたい度合い」が変化したユーザーの割合
  - 特に「とても飼いたい → 迷っている」など、慎重になった変化を重視
- **気づき取得率**: 「気づきがあった」と回答したユーザーの割合
- **満足度**: 「役立った」と回答したユーザーの割合
- **定性フィードバック**: 自由記述から具体的な気づきの内容を分析
